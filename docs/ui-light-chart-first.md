# UI Light Chart-First Slice

This document records the product UI boundary for Issue #5.

## Architecture decision

- Keep the existing Python + HTML/CSS/JavaScript + Chart.js structure.
- React / Vite / Next.js are NOT introduced.
- The dashboard UI ships as static assets generated by the Python pipeline:
  - `fmindex/dashboard/templates/index.html`
  - `fmindex/dashboard/static/css/dashboard.css`
  - `fmindex/dashboard/static/js/dashboard.js`
- Final pipeline output paths:
  - `output/index.html`
  - `output/css/dashboard.css`
  - `output/js/dashboard.js`
  - `output/api/data.json`

## Implemented

- Light theme as the default, with an optional persistent dark theme (`localStorage`)
- Chart-first home layout rather than a copied board list
- KOSPI / NASDAQ selector: the NASDAQ market series is `unavailable` and is never relabeled from KOSPI values
- 24h / 7d / 30d / all timestamp filters anchored to the latest valid record
- Companion / lead / divergence view controls
- Korea / US / custom rise-fall color modes stored in `localStorage`
- URL deep linking: `?theme=&colors=&market=&period=&view=&up=&down=`
- Explicit SAMPLE DATA badge and unavailable states (no fabricated numbers)
- Domestic overnight and US-session panel structures (unavailable until real session data)
- Accessible shell: skip link, `aria-live` chart status, `aria-pressed` controls, Escape-close settings
- Responsive desktop layout and a fixed mobile bottom navigation
- Static HTML/CSS/JavaScript assets exported by the Python pipeline and packaged in the wheel via `package-data`

## Intentionally unavailable

- Real KOSPI and NASDAQ data
- Real overnight futures data
- Live FMKorea collection
- Real lead-lag or direction-agreement percentages
- Real topic extraction

The UI renders unavailable states instead of inventing financial results.

## No live API calls

The pipeline runs fully offline: market data comes from local 65stock files or
deterministic sample data; LLM analysis uses the offline provider; no real
FMKorea, market, or LLM API is called.


color settings, deep links, and the mobile bottom navigation at desktop and
