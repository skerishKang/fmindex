# FMIndex 제품 정의

## 1. 한 문장 정의

FMIndex는 한국 개인투자자 커뮤니티의 게시글과 댓글을 시간대별로 분석해 **시장 방향성, 감정, 행동 의도, 관심 급증, 의견 분열**을 지수화하는 로컬 우선 시장심리 연구 플랫폼이다.

## 2. 브랜드 구조

- 공개 지수명: **펨코지수**
- 내부 제품명: **FMIndex**
- 확장 가능한 엔진명: **K-Retail Sentiment Engine**

FMKorea는 첫 번째 데이터 원천일 뿐이며, 장기적으로 제품 구조가 특정 사이트에 종속되지 않도록 데이터 원천 어댑터와 분석 엔진을 분리한다.

## 3. 해결하려는 문제

기존 주식 뉴스·차트 서비스는 가격, 공시, 기사 중심이다. 그러나 개인투자자가 실제로 느끼는 공포·과열·체념·관망과 같은 심리 변화는 정형 데이터로 제공되지 않는다. 게시판을 직접 읽으면 분위기를 파악할 수 있지만 다음 문제가 있다.

- 게시물 수가 많아 전체 흐름을 지속적으로 보기 어렵다.
- 표면적인 긍정·부정 표현과 실제 의미가 다르다.
- 반어, 밈, 은어, 조롱, 인용을 일반 감성분석이 오판한다.
- 특정 시점의 분위기를 나중에 재현하기 어렵다.
- 언급량 급증과 심리 급변을 가격 데이터와 함께 비교하기 어렵다.

FMIndex는 원문을 다시 보여주는 서비스가 아니라 이러한 흐름을 **재현 가능한 파생 데이터**로 변환한다.

## 4. MVP 사용자

### 4.1 일반 투자자

- 지금 커뮤니티 분위기가 과도하게 낙관적인지 공포스러운지 확인한다.
- 게시판 심리와 실제 가격이 엇갈리는 종목을 탐색한다.
- 어떤 업종·종목의 관심이 갑자기 커졌는지 확인한다.

### 4.2 연구자·콘텐츠 제작자

- 개인투자자 심리의 시계열 변화를 분석한다.
- 장중 사건 전후 커뮤니티 반응을 비교한다.
- 일일·주간 시장심리 보고서를 작성한다.

### 4.3 내부 운영자

- 수집 누락, 중복, 요청 제한, 모델 오류를 확인한다.
- 지수 변화에 기여한 데이터와 모델 버전을 감사한다.
- 낮은 확신도의 분석 표본을 검수한다.

## 5. MVP 핵심 질문

1. 현재 게시판은 시장을 상승·하락·중립 중 어느 방향으로 보고 있는가?
2. 현재 심리는 15분·1시간 전과 비교해 얼마나 변했는가?
3. 공포·탐욕·불안·분노·환희·체념 중 무엇이 우세한가?
4. 어떤 시장·업종·종목의 언급량이 기준선보다 급증했는가?
5. 긍정과 부정 의견이 한쪽으로 모였는가, 강하게 분열됐는가?
6. 커뮤니티 심리와 실제 시장가격은 동행하는가, 괴리되는가?

## 6. MVP 기능 범위

### 포함

- FMKorea 주식 게시판 목록의 저빈도 증분 관찰
- 중요 게시글의 선택적 본문 수집
- 영향도가 높은 게시글의 제한적 댓글 수집
- 시장·업종·종목 대상 인식
- 방향성, 감정, 행동 의도, 시간 범위, 반어 가능성 분석
- 15분 단위 지수 집계
- 지수 산식·모델·프롬프트 버전 기록
- 수집·분석 품질 내부 콘솔
- 원문을 재배포하지 않는 공개 대시보드

### 제외

- 매수·매도 추천
- 자동매매
- 미래 수익률 보장
- 작성자 개인 랭킹 또는 신뢰점수 공개
- 원문 전체 검색·재게시
- 접근 제한·인증·CAPTCHA 우회
- 여러 커뮤니티의 동시 출시
- 유료 투자 신호 판매

## 7. 지수 체계

### 7.1 시장심리지수

0부터 100까지 표현하며 50을 중립 기준으로 둔다.

- 0~20: 극단적 부정
- 21~40: 부정
- 41~59: 중립
- 60~79: 긍정
- 80~100: 극단적 긍정

### 7.2 공포·탐욕지수

방향성과 별도로 감정의 성격과 강도를 측정한다. 상승 기대가 있어도 불안이 높을 수 있으므로 시장심리지수와 분리한다.

### 7.3 관심도지수

게시글 수, 댓글 수, 고유 참여자 수, 증가율을 기준선과 비교한다. 단순 총량이 아니라 시간대·요일별 정상 수준을 기준으로 한다.

### 7.4 의견분열지수

긍정과 부정이 동시에 강한 상태를 포착한다. 평균 심리가 중립이어도 실제로는 의견 충돌이 심할 수 있다.

### 7.5 심리변화속도

15분, 1시간, 전일 동일 시각 대비 지수 변화량을 제공한다.

### 7.6 시장괴리지수

실제 가격·거래량과 커뮤니티 심리의 방향·강도 차이를 측정한다. 이 값은 투자 신호가 아니라 관측 지표로 제공한다.

## 8. 제품 성공 기준

### Phase 0 성공 기준

- 저빈도 수집으로 신규 게시물을 식별할 수 있다.
- 중복·누락·실패를 측정할 수 있다.
- 데이터 원천 구조와 요청 제한 양상을 문서화했다.
- 원문 보존·삭제 정책을 구현할 수 있다.
- 분석 스키마와 사람 라벨링 기준을 확정했다.

### 분석 MVP 성공 기준

- 시장 관련성 분류 정확도 90% 이상
- 긍정·중립·부정 Macro F1 0.80 이상
- 대상 인식 정확도 90% 이상
- JSON 스키마 유효성 99.5% 이상
- 동일 입력 재실행 결과 일치율 99% 이상
- 낮은 확신도 결과가 자동으로 검수 큐에 들어간다.

### 공개 MVP 성공 기준

- 장중 지수가 지정 주기로 생성된다.
- 지수 생성에 사용된 유효 표본 수가 표시된다.
- 수집 지연 또는 표본 부족 상태가 숨겨지지 않는다.
- 지수 변화의 주요 기여 요인을 설명할 수 있다.
- 원문 전체와 작성자 식별정보를 공개하지 않는다.

## 9. 핵심 제품 원칙

1. **관측을 먼저 하고 예측은 나중에 검증한다.**
2. **지수 숫자보다 재현성과 설명 가능성을 우선한다.**
3. **모델이 아니라 데이터 시계열과 분류체계를 자산으로 만든다.**
4. **접근 제한을 우회하지 않고 요청량을 최소화한다.**
5. **원문 복제보다 파생 데이터와 연구 결과를 축적한다.**
6. **실패·지연·표본 부족을 정상 값처럼 표시하지 않는다.**

## 10. 공개 문구

> 펨코지수는 공개 게시판에서 관찰되는 집단적 시장심리를 통계적으로 요약한 연구 지표입니다. 투자 권유, 투자자문, 매매 신호 또는 수익 보장을 의미하지 않습니다.
